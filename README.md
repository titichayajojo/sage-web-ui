
# Sage Web UI

Sage Web UI is a frontend project built using Next.js, a popular React framework, with a focus on performance and scalability. This project is bootstrapped with `create-next-app` and includes essential configurations and styling to get started quickly.

## Features

- **Next.js Framework**: Utilizes Next.js for server-side rendering, static site generation, and optimized performance.
- **Custom Styling**: Includes custom styles with CSS, tailored to fit the project's needs.
- **API Routes**: Pre-configured API routes for backend interaction.
- **Responsive Design**: Ensures a seamless experience across devices.

## Getting Started

### Prerequisites

- Node.js (v14 or later)
- npm, yarn, or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/titichayajojo/sage-web-ui.git
   cd sage-web-ui
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

### Deployment

The project can be easily deployed on Vercel, the platform built by the creators of Next.js. Follow the [Next.js deployment documentation](https://nextjs.org/docs/deployment) for detailed instructions.

## Project Structure

- **`pages/`**: Contains the application routes, including API routes in `pages/api`.
- **`public/`**: Static assets like images, fonts, etc.
- **`styles/`**: Global and component-specific CSS files.
